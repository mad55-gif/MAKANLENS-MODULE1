# MAKANLENS-MODULE1
MAKANLENS-MH FOOD RECOGNITION

1. Install Python and VS Code.
2. Open the project folder in VS Code.
3. Install required libraries:
   pip install -r requirements.txt
4. Open src/train.ipynb.
5. Select the correct Python environment.
6. Run the notebook cells in order.

The notebook compares MobileNetV2, ResNet50V2 and EfficientNetB0
for Malaysian food image recognition.

The dataset contains 17 food classes.
